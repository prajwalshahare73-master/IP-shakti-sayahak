1. What is IP Classification?
What is IP Classification?
IP classification means organizing IP rights (patents, trademarks, designs, GI, copyright) into standardized
categories so that similar subject matter can be searched, examined, and managed systematically.
Classification makes it easier to search prior art, examine applications, and understand the scope of
protection. It also helps applicants choose the right classes/categories when filing.
 Patents: International Patent Classification (IPC) and Cooperative Patent Classification (CPC).
 Trademarks: Nice Classification (classes of goods/services).
 Designs: Locarno Classification (classes for industrial designs).
 GI: Classes under GI Rules (goods categories).
 Copyright: Categories of works (literary, dramatic, musical, artistic, film, sound recording, etc.).
 A patent on an herbal extraction process may be classified under IPC/CPC sections for chemistry/pharmacy.
 An Ayurvedic brand for medicines is filed in Trademark Class 5; for cosmetics, Class 3.
 A uniquely shaped Ayurvedic oil bottle may be classified under a specific Locarno class for containers.
IP India (CGPDTM); Copyright Office; WIPO (for international classification systems).

 Issuing authority: IP India / DPIIT; WIPO; Copyright Office

Correct classification is critical for effective search and examination. Misclassification can lead to missed prior art or
objections.
This guide is introductory; detailed classification requires familiarity with each system’s rules and schemes.

2. Patent Classification (IPC / CPC)
Patent Classification (IPC / CPC)
Patent classification organizes patent documents by technical field using standardized codes. The main
systems are IPC (International Patent Classification) and CPC (Cooperative Patent Classification).
Classification helps examiners and applicants find relevant prior art and understand the technical area of an
invention. It is essential for effective patent search and examination.
 IPC: Hierarchical system with sections (A–H), classes, subclasses, groups, and subgroups (e.g., A61K for preparations
for medical/dental/toilet purposes).
 CPC: Extension of IPC with finer granularity, jointly managed by EPO and USPTO; widely used for search.
 Indian Patent Office uses IPC/CPC for classification of patent applications and prior art search.
 An Ayurvedic formulation for treating diabetes may be classified under A61K (medical preparations) with further
subgroups for plant extracts.
 A new extraction process for herbal actives may be classified under C11B (fats, fatty substances, waxes) or C07D
(organic chemistry) depending on technical features.
 A device for administering Ayurvedic medicine (e.g., special dropper) may be classified under A61M (devices for
introducing media into the body).
Indian Patent Office (CGPDTM); WIPO (IPC); EPO/USPTO (CPC).
 Source title: WIPO IPC page; EPO CPC page; IP India – Patents resources
 Issuing authority: WIPO; EPO; IP India
 URL: https://www.wipo.int/classifications/ipc/ ; https://www.epo.org/searching-for-patents/classification/cpc.html ;
https://ipindia.gov.in/
When drafting a patent application, think about all possible IPC/CPC classes that might apply (composition, process,
device, use). This improves search quality and reduces risk of missed prior art.
Detailed CPC/IPC assignment is done by examiners; applicants can suggest but not fix classification.

3. Trademark Classification (Nice Classes)
Trademark Classification (Nice Classes)
Trademark classification uses the Nice Agreement system, which divides goods and services into 45 classes
(1–34 for goods, 35–45 for services). Each application must specify the class(es) and items covered.
Correct classification ensures your trademark protects the right products/services and avoids conflicts. Fees
are often per class, so class strategy affects cost.
 Nice Classification (11th edition currently): 45 classes.
 India follows Nice Classification under Trade Marks Rules, 2017.
 Each class has a general heading and alphabetical list of goods/services.
 Class 5: Pharmaceutical, veterinary, and sanitary preparations; Ayurvedic medicines fall here.
 Class 3: Cosmetics, hair oils, soaps; Ayurvedic hair oils and skincare products often filed here.
 Class 35: Advertising, business management, online retail services for Ayurvedic products.
 Class 44: Medical services; Ayurvedic clinics/consultancies may file here for services.
Trade Marks Registry (CGPDTM), IP India.
 Source title: Trade Marks Rules, 2017; IP India – Trade Marks resources; WIPO Nice Classification
 Issuing authority: IP India / DPIIT; WIPO
 URL: https://ipindia.gov.in/ ; https://www.wipo.int/classifications/nice/
For Ayurvedic brands, common strategy is to file in Class 5 (medicines) and/or Class 3 (cosmetics), plus Class 35/44 if
offering retail/clinic services. Always check the latest edition of Nice Classification for exact items.
This is a general guide; specific goods/services may fall in unexpected classes and require professional advice.

4. Design Classification (Locarno)
Design Classification (Locarno)
Design classification uses the Locarno Agreement system, which organizes industrial designs into classes
and subclasses based on the type of article to which the design is applied.
Classification helps in searching existing designs and examining new applications. It ensures similar designs
are grouped together.
 Locarno Classification: 32 classes for different types of articles (e.g., packaging, containers, furniture, clothing).
 India follows Locarno Classification under Designs Rules.
 Each class has subclasses and an alphabetical list of articles.
 Class 9: Packages and containers for transport/handling of goods; Ayurvedic oil bottles, jars, and boxes often fall here.
 Class 24: Medical and laboratory equipment; Ayurvedic devices/instruments may be classified here.
 Class 6: Furnishing; if designing Ayurvedic spa furniture, this class may apply.
Designs Office (CGPDTM), IP India.
 Source title: Designs Rules, 2001; IP India – Designs resources; WIPO Locarno Classification
 Issuing authority: CGPDTM / DPIIT; WIPO
 URL: https://ipindia.gov.in/ ; https://www.wipo.int/classifications/locarno/
When registering a design for packaging or a product, identify the primary function and article type to choose the correct
Locarno class. This affects search and examination.
Design classification is technical; borderline cases (multi■function articles) may need expert input.

5. GI Classification (GI Classes under GI Rules)
GI Classification (GI Classes under GI Rules)
GI classification groups geographical indications by categories of goods (e.g., agricultural goods, foodstuffs,
handicrafts) under the GI Rules. Applications must specify the class of goods.
Classification ensures GI applications are examined against similar GIs and helps users search the GI
register.
 GI Rules 2002 (as amended) prescribe classes of goods for GI registration.
 Classes include categories such as agricultural goods, foodstuffs, handicrafts, industrial goods, etc.
 Each GI application identifies the relevant class and provides details of the product and territory.
 An Ayurvedic herbal product with strong regional reputation (e.g., a specific regional formulation) could be considered
under agricultural/foodstuff classes if it meets GI criteria.
 Handicraft items related to Ayurveda (e.g., traditional medicinal■■) may fall under handicraft classes.
GI Registry (CGPDTM), IP India.
 Source title: GI Act 1999; GI Rules 2002 as amended 2025; IP India – GI resources
 Issuing authority: DPIIT / GI Registry

GI is less common for standard Ayurvedic medicines but may be relevant for region■specific products with established
reputation linked to origin.
GI classification details are in the Rules; specific cases require checking the latest official schedule.

6. Copyright Work Categories
Copyright Work Categories
Copyright classification in India is based on categories of works: literary, dramatic, musical, artistic,
cinematograph films, and sound recordings. Each category has specific treatment under the Copyright Act.
Correct category determines the applicable fee, form details, and scope of protection. It also affects duration
and ownership rules.
 Literary works: books, articles, software, compilations, tables.
 Dramatic works: plays, recitations, choreographic works.
 Musical works: music compositions (excluding lyrics/sound recordings).
 Artistic works: paintings, drawings, logos, labels, sculptures, photographs.
 Cinematograph films: video recordings with sound.
 Sound recordings: recordings of sounds (including music, spoken word).
 An Ayurvedic textbook or monograph is a literary work.
 Label artwork and logos for Ayurvedic products are artistic works.
 Training videos on Ayurvedic therapies are cinematograph films.
 Recorded chants or audio guides for Ayurvedic practices are sound recordings.
Copyright Office, Department for Promotion of Industry and Internal Trade (DPIIT).
 Source title: The Copyright Act, 1957; Copyright Rules, 2013; Copyright Office
 Issuing authority: Copyright Office / DPIIT
 URL: https://copyright.gov.in/
Software for managing Ayurvedic clinics or formulations is protected as a literary work (computer program). Labels/logos
may also be trademarks, so consider dual protection.
Borderline cases (e.g., databases, compilations) require careful analysis of originality and category.

7. Practical Examples (Ayurveda & General)
Example 1: Ayurvedic Pain■Relief Oil
Product: Herbal pain■relief oil based on classical formulation, sold under a new brand.
IP Classification:
 Patent: If novel process/composition, classify under IPC/CPC for medical preparations (A61K) and/or extraction
processes (C11B, C07D).
 Trademark: Brand name/logo in Class 5 (pharmaceuticals) and/or Class 3 (cosmetics) depending on claims.
 Design: Unique bottle shape/packaging in Locarno Class 9 (containers).
 Copyright: Label text/artwork as literary/artistic work; brochures as literary works.
Example 2: Ayurvedic Clinic Chain
Business: Chain of Ayurvedic clinics offering therapies and selling products.
IP Classification:
 Trademark: Brand name/logo in Class 44 (medical services), Class 5 (medicines), Class 35 (retail/advertising).
 Copyright: Website content, training manuals, videos as literary/artistic/film works.
 Design: Clinic interior design elements may be protected under copyright (artistic works) or design (if applied to articles).
Example 3: Software for Ayurvedic Formulations
Product: Software that suggests Ayurvedic formulations based on symptoms.
IP Classification:
 Patent: If technically novel (e.g., new algorithm with technical effect), may be patentable subject to Section 3(k).
 Trademark: Software name/logo in Class 9 (software) and/or Class 42 (software services).
 Copyright: Software code as literary work; UI graphics as artistic works.
