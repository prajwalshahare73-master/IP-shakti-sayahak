1. Common Practical IP/Ayurveda FAQs
I have an Ayurvedic formulation. Should I file a patent?
Simple Answer
File a patent only if the formulation or process is truly new, non■obvious, and not already described in
classical texts/TKDL. Many classical formulations are prior art and not patentable.
What It Means
Patentability depends on novelty, inventive step, and not falling under exclusions (e.g., traditional knowledge
per se).
Key Points
 Check classical texts and TKDL context first.
 New combinations, improved processes, or specific standardized extracts may be patentable.
 Patentability requires claim■level analysis against prior art.
Step-by-Step Process
1. Conduct prior art search (patents + classical texts/TKDL).
2. Assess novelty and inventive step.
3. If promising, draft claims focusing on technical advance.
4. File patent only after positive assessment.
Relevant IP Types
 Patents (if novel/inventive)
 Trade secrets (if keeping process confidential)
Regulatory / Other Considerations
 Ensure product classification (ASU drug/cosmetic/food) is clear before commercialization.
 Filing patent for a classical formulation already in texts/TKDL.
 Publicly disclosing formulation before filing.
 Ignoring non■patent prior art (journals, textbooks).
A new standardized extract process with improved bioavailability may be patentable; a classical churna from Charaka
Samhita likely is not.
 Source title: Patents Act 1970; IP India; TKDL documentation
 Issuing authority: IP India; CSIR■TKDL
 URL: https://www.ipindia.gov.in/resource/patents-resources-act

This is general guidance; each formulation requires technical/legal assessment.
Should I trademark my Ayurvedic brand name?
Simple Answer
Yes, if you plan to build a brand. Trademark protects the name/logo, not the formulation. File in relevant
classes (e.g., Class 5 for medicines, Class 3 for cosmetics).
What It Means
Trademark is often more important than patent for Ayurvedic brands, especially for classical formulations.
Key Points
 File early, before market launch.
 Choose distinctive names (avoid descriptive/generic terms).
 Search for conflicting marks before filing.
Step-by-Step Process
1. Search existing trademarks (tmrsearch.ipindia.gov.in).
2. Identify relevant classes (3, 5, 35, 44, etc.).
3. File TM■A application.
4. Monitor and renew every 10 years.
Relevant IP Types
 Trademarks
Regulatory / Other Considerations
 Ensure brand name does not make unauthorized drug claims.
 Choosing a descriptive name (e.g., 'Best Ayurvedic Medicine').
 Filing in wrong classes.
 Ignoring earlier conflicting marks.
Brand 'VedaCare' for Class 5 (medicines) and Class 3 (cosmetics) is a typical strategy.
 Source title: Trade Marks Act 1999; IP India
 Issuing authority: IP India / DPIIT
 URL: https://ipindia.gov.in/
Registrability depends on distinctiveness and conflicts.

Can I protect my Ayurvedic product packaging?
Simple Answer
Yes, via design registration for unique shape/pattern, and copyright for label artwork. Trademark can protect
logo/brand on packaging.
What It Means
Design protects appearance, not function. Copyright protects artistic elements automatically; registration
strengthens evidence.
Key Points
 Design registration for distinctive bottle/box shape.
 Copyright for label text/images.
 Trademark for logo/brand on packaging.
Relevant IP Types
 Designs
 Copyright
 Trademarks
Regulatory / Other Considerations
 Label must comply with drug/cosmetic/food labeling rules.
 Trying to protect functional features via design.
 Copying label artwork from others.
A uniquely shaped Ayurvedic oil bottle can be registered as a design; label artwork is copyrighted.
 Source title: Designs Act 2000; Copyright Act 1957; Trade Marks Act 1999
 Issuing authority: IP India; Copyright Office
 URL: https://ipindia.gov.in/ ; https://copyright.gov.in/
Design must be new/original; copyright is automatic.
Do I need ABS approval for my Ayurvedic startup using Indian herbs?
Simple Answer
Many Indian entities using Indian biological resources for commercial purposes need to engage with State
Biodiversity Boards and possibly NBA, depending on category and source. Early ABS assessment is critical.

What It Means
ABS obligations depend on resource origin, user category, and use (research/commercial/IPR).
Key Points
 Map all herbs and their sources (state, district, collector).
 Check latest Rules for exemptions/approval needs.
 File ABS application and sign ABS agreement where required.
 Disclose source in any patent applications.
Relevant IP Types
 Patents (source disclosure)
 Trade secrets (processes)
Regulatory / Other Considerations
 Biological Diversity Act 2002 (as amended 2023); NBA/State Board approvals.
 Assuming cultivated herbs are always exempt.
 Ignoring ABS until late in product development.
Startup in Uttarakhand uses local herbs; engages with State Biodiversity Board, signs ABS agreement with benefit
sharing to local communities.
 Source title: Biological Diversity Act 2002; NBA portal
 Issuing authority: NBA; MoEFCC
 URL: https://nbaindia.nic.in/
Specific obligations depend on exact resources and state rules.
Is my Ayurvedic product a drug, cosmetic, or food?
Simple Answer
Classification depends on ingredients, claims, and intended use. Therapeutic claims → ASU drug;
cleansing/beautifying → cosmetic; nutrition/health support → food/nutraceutical.
What It Means
Wrong classification leads to licensing and labeling issues.
Key Points
 ASU drugs: therapeutic claims; ASU drug licence.
 Cosmetics: external use for cleansing/beautifying; cosmetic licence.

 Food/nutraceuticals: ingestion for nutrition/health support; FSSAI licence.
Step-by-Step Process
1. List all ingredients and claims.
2. Map to ASU drug / cosmetic / food category.
3. Obtain appropriate licence.
4. Ensure labeling complies with chosen category.
Relevant IP Types
 Trademarks (brand)
 Patents (if novel formulation)
Regulatory / Other Considerations
 Drugs & Cosmetics Act; Cosmetics Rules; FSS Act.
 Making drug claims for a cosmetic or food product.
 Filing for food licence while making therapeutic claims.
Herbal hair oil with cosmetic claims (nourishes hair) is a cosmetic; same oil with therapeutic claims (treats hair loss due to
medical condition) may be a drug.
 Source title: Ministry of AYUSH; FSSAI; Drugs & Cosmetics Act
 Issuing authority: Ministry of AYUSH; FSSAI
 URL: https://ayush.gov.in/ ; https://fssai.gov.in/
Borderline cases need expert regulatory advice.

2. Real■World Scenarios (Startups, Clinics, Researchers,

Scenario 1: Ayurvedic Startup with New Herbal Formulation
User Question
We developed a new Ayurvedic formulation for joint pain. Should we patent, trademark, or both?
Detected Intent
Determine IP and regulatory strategy for a new Ayurvedic product.
Situation
Startup has a proprietary herbal formulation for joint pain, plans to sell as ASU drug.
Key Issues to Check
 Is formulation truly novel vs classical/TK?
 What regulatory category (ASU drug/cosmetic/food)?
 Brand name and packaging protection.
Recommended Workflow
1. Conduct prior art/TK search.
2. If novel, consider patent; else focus on trademark/design.
3. File trademark for brand in Class 5 (and others as needed).
4. Obtain ASU drug manufacturing licence.
5. Check ABS obligations for herbs used.
IP / Regulatory Areas
 Patents (if novel)
 Trademarks
 Designs (packaging)
 ASU drug licence
 ABS compliance
 Filing patent without prior art search.
 Ignoring ABS until late stage.
 Choosing descriptive brand name.
Startup files trademark 'JointVeda' in Class 5, obtains ASU drug licence, and after positive patentability opinion, files
patent on specific extract process.
 Source title: IP India; Ministry of AYUSH; NBA
 Issuing authority: IP India; Ministry of AYUSH; NBA
 URL: https://ipindia.gov.in/ ; https://ayush.gov.in/ ; https://nbaindia.nic.in/

Each case needs specific technical/regulatory analysis.
Scenario 2: Ayurvedic Clinic Launching Own Product Line
User Question
We run an Ayurvedic clinic and want to sell our own oils and supplements. What IP and regulatory steps are
needed?
Detected Intent
Understand combined IP/regulatory needs for clinic + products.
Situation
Clinic wants to brand and sell own line of Ayurvedic products.
Key Issues to Check
 Product classification (drug/cosmetic/food).
 Manufacturing/licensing pathway.
 Brand protection (trademark).
Recommended Workflow
1. Classify each product (drug/cosmetic/food).
2. Obtain respective manufacturing/third■party licences.
3. File trademarks for clinic and product brands.
4. Ensure labeling compliance for each category.
IP / Regulatory Areas
 Trademarks
 ASU drug/cosmetic/FSSAI licences
 Copyright (brochures/website)
 Selling unlicensed products.
 Using same brand for clinic and products without proper trademark strategy.
Clinic registers trademark 'AyurHeal' for services (Class 44) and products (Class 5), contracts third■party manufacturer
with ASU licence, and sells labeled products.

 Issuing authority: Ministry of AYUSH; FSSAI; IP India
 URL: https://ayush.gov.in/ ; https://fssai.gov.in/ ; https://ipindia.gov.in/

Scenario 3: Researcher Collaborating with Foreign University
User Question
We are collaborating with a foreign university on Indian medicinal plants. What ABS and IP steps are
needed?
Detected Intent
Determine ABS and IP obligations for cross■border research.
Situation
Indian lab sharing plant extracts/data with foreign partner; potential joint IPR.
Key Issues to Check
 Foreign access to Indian biological resources/TK.
 ABS approval and benefit sharing.
 Joint IPR ownership and disclosure.
Recommended Workflow
1. Identify all biological resources/TK to be shared.
2. File NBA application for foreign access and research.
3. Negotiate ABS agreement covering research and potential IPR.
4. Ensure any IPR applications disclose source and ABS compliance.
IP / Regulatory Areas
 Patents (joint)
 ABS (NBA approval)
 Contracts (IP ownership)
 Sharing resources before NBA approval.
 Not defining IP ownership in collaboration agreement.
Indian institute shares extracts under NBA■approved ABS agreement; joint patent application discloses source and
benefit sharing terms.
 Source title: NBA portal; Biological Diversity Act
 Issuing authority: NBA; MoEFCC
 URL: https://nbaindia.nic.in/

Collaborations can be complex; involve legal/ABS experts early.
Scenario 4: Exporter of Ayurvedic Products
User Question
We manufacture Ayurvedic products in India and export them. Do ABS and IP rules apply?
Detected Intent
Determine ABS/IP obligations for export■oriented Ayurvedic business.
Situation
Company exports finished Ayurvedic products; uses Indian herbs.
Key Issues to Check
 Underlying resource access obligations.
 IP protection in target markets.
 Labeling compliance for export countries.
Recommended Workflow
1. Map biological resources used in products.
2. Check ABS obligations for your user category.
3. File trademarks in key export markets (via Madrid or national filings).
4. Ensure labeling meets destination country rules.
IP / Regulatory Areas
 Trademarks (international)
 ABS (if applicable)
 Export labeling regulations
 Assuming export exempts ABS.
 Not protecting brand in export markets.
Exporter confirms ABS compliance for herb access, files international trademark via Madrid, and adapts labels for EU/US
markets.
 Source title: NBA; IP India; WIPO (Madrid)
 Issuing authority: NBA; IP India; WIPO
 URL: https://nbaindia.nic.in/ ; https://ipindia.gov.in/ ; https://www.wipo.int/madrid/

Export regulations vary by country; verify per market.
